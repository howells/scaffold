PatternMode splits UI, motion, transitions, and Tailwind tokens into four packages.

## Packages

- `@patternmode/ui`: Base UI-backed React components styled with Tailwind CSS.
- `@patternmode/motion`: springs, durations, easing curves, and semantic presets.
- `@patternmode/transition`: shared-element transitions, dismissible overlays, and coordinated sequences.
- `@patternmode/tailwind-config`: Tailwind v4 tokens and base styles.
