# Scaffold

The house standard for starting or aligning a Howells project.

`docs/` is canonical. The Next.js app renders those files for browsing.

Start with [docs/README.md](docs/README.md). The philosophy behind the baseline lives in [docs/principles.md](docs/principles.md).

## Commands

```sh
pnpm install
pnpm dev
pnpm check
```

## Agent skill

The installable skill at `skills/scaffold` applies the standard to new or existing projects.
